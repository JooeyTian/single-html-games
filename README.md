# 单 HTML 游戏 / 工具集合

一个用于存放**单文件 HTML**小游戏和小工具的工程。原则是：**一个应用 = 一个独立文件夹 = 一个 `index.html` 入口**，应用之间彼此隔离，互不引用、互不污染。

## 核心约定

1. **一个应用一个文件夹**，文件夹名即应用名，使用小写英文 + 连字符（如 `memory-match`）。
2. **入口统一为 `index.html`**，直接双击用浏览器打开即可运行。
3. **单文件优先**：CSS 写在 `<style>` 里，JS 写在 `<script>` 里，尽量不依赖外部资源，保证离线可用。
4. **应用之间完全隔离**：
   - 不要跨文件夹引用另一个应用的代码或资源；
   - 每个应用只使用自己文件夹内的文件；
   - 需要复用代码时，复制到各自文件夹中，保持独立。
5. **多文件应用也允许**：如果某个应用不适合单 HTML，就把它拆成多个文件，但全部放在它自己的文件夹里，入口仍然是 `index.html`。
6. `_template` 是模板，永远不要直接改它；新增应用请复制它。
7. 首页卡片使用各应用自己的 `thumbnail.jpg` 作为缩略图（建议 16:9、游戏内截图），文件放在该应用文件夹内，不共享、不跨引用。

## 如何运行

- 单个应用：进入对应文件夹，双击 `index.html`（或拖入浏览器）。
- 游戏平台首页：双击根目录的 `index.html`，在卡片上点击「开始游戏」进入对应应用（新标签页打开，也可直接双击应用文件夹里的 `index.html`）；首页支持按名称搜索和按标签筛选。
- 需要本地服务器时（例如用到 `fetch` 或某些浏览器 API），在根目录执行：

```powershell
python -m http.server 8000
```

然后访问 `http://localhost:8000/apps/<应用名>/`。

## 如何新增应用

**方式一：脚本（推荐）**

在项目根目录执行：

```powershell
.\scripts\new-app.ps1 my-new-game
```

脚本会从 `_template` 复制出 `apps/my-new-game/index.html`。若 PowerShell 提示禁止执行脚本，可使用：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\new-app.ps1 my-new-game
```

**方式二：手动**

1. 复制 `apps/_template` 文件夹，重命名为你的应用名；
2. 编辑其中的 `index.html`，填写标题和你的代码；
3. 给应用截一张图，存为 `apps/你的应用名/thumbnail.jpg`（16:9 左右效果最好）；
4. 在根目录 `index.html` 的 `.grid` 里复制一张 `.game-card`，改 `href`、`img src`、标签（`data-title` / `data-tags` / `data-desc`）和文字；标签目前有 `action`（动作）、`idle`（放置）、`sim`（模拟）、`puzzle`（益智）、`strategy`（策略）、`retro`（复古）；
5. 在本 README 的应用清单里登记一行说明。

## 三款新游戏的设计思路

三款都瞄准「一局只要几十秒、结束就想再来」的成瘾循环，但爽点各不相同：

| 游戏 | 核心循环 | 上瘾钩子 | 失败/结束条件 |
| --- | --- | --- | --- |
| 叠叠塔 | 看准来回移动的方块 → 点击落下 → 切掉重叠部分继续叠 | PERFECT 精准判定给连击与额外分；每 5 连击方块「回血」变宽；速度随层数上升 | 完全错位没重叠 |
| 合成大西瓜 | 瞄准落点 → 投下水果 → 同级碰撞升级 → 连锁反应 | 连锁倍率、11 级水果图鉴、合成大西瓜的收集欲 | 堆过危险线持续 2 秒 |
| 六角拼图 | 拖动形状 → 旋转 → 落子 → 填满整行消除 | 三方向消行、连续消行倍率、长线一次清掉的高收益 | 任何形状都无处可放 |

共同设计手段：最高分本地存档（刷新不丢）、WebAudio 合成音效（无外部资源）、粒子与震屏反馈、鼠标 / 触摸 / 键盘三套输入、窄屏自动隐藏侧栏并放大按钮。缩略图未提供时首页卡片自动回退为 emoji 图标。

## 机甲远征的设计（取代上面两款被动模拟）

之前的地牢领主与武侠门派问题在于「玩家只看数字涨、操作少、反馈慢」。机甲远征改为四个层次同时给反馈：

| 层次 | 玩家在做什么 | 反馈周期 | 决策点 |
| --- | --- | --- | --- |
| 秒级战斗 | WASD / 摇杆走位、闪避、Q/E/R 技能、自动射击 | 每次命中都有伤害数字、粒子、震屏、连击 | 走位、何时闪避、技能时机、热量控制 |
| 分钟级成长 | 击杀累积经验，升级三选一 | 每十几次击杀就弹出强化选择 | 10 种强化决定本局 Build 方向 |
| 星区级策略 | 6 个星区，每个选标准 / 精英 / 补给航线，星区结束挑模块 | 每 45–70 秒一次结算 | 风险航线换更好掉落；模块槽位与三品牌套装 |
| 跨局养成 | 芯片带回机库，强化生命 / 引擎 / 武器 / 散热 / 复活 | 每局结束立刻变强 | 永久属性投向哪条线 |

存档策略：元进度（芯片、机库强化、纪录）与当前远征快照都自动写入 localStorage；关闭页面进度即停，不做离线收益。PC 用键盘 + 鼠标，手机用左侧虚拟摇杆 + 右侧四个大按钮。

## 废土自动工厂

直接打开 `apps/wasteland-foundry/index.html` 即可玩，全部逻辑、样式和绘图内嵌，无网络依赖。

- 起步：用初始 ¥100 建好熔炼炉、制造机、货运站，形成自动生产线；之后以大型扩建为主，普通等级与专精收在基础设备面板。
- 扩建：双线枢纽建立独立副线；调度塔接管日常采购；蜂群定时回收材料；电子区卖芯片；电站回收熔炉废热。装配厂消耗真实零件与芯片制造最多 64 台工人，铁路每 15 秒批量交付，移动工厂每 30 秒回收一处废墟。
- 经营：可优先投资产线规模、采集队或副产业，机器人装配 / 芯片外售可切换。卡车、芯片、电力、列车、残骸与旧城分红分别计入收入账本。
- 迁厂：本轮产值达到 ¥25K 后可熔铸核心，保留核心、科技和蓝图。新地区重建设备与工程；旧工厂留下本轮平均产业收入的 15% 为永久分红，合计上限 ¥10K / 秒。
- 存档：每 10 秒及离开页面时保存，默认最多结算 12 小时离线进度，科技可提高至 24 小时。设置内可导入 / 导出 JSON 备份。
- 手机：底部导航切换生产、订单与拆解、核心科技和设置；单列设备卡片及主要按钮提供至少 44px 触控区域，弹窗关闭后恢复原滚动位置，并适配安全区和动态视口。
- Safari 主屏幕：通过 HTTPS 页面分享菜单添加到主屏幕；本地文件预览不等同于可安装 PWA。单 HTML 内置主屏幕元信息和图标，离线收益可计算；断网冷启动需要托管站点另行提供离线缓存。浏览器与主屏幕入口切换前建议导出存档。
- 存档兼容：版本 1 存档会自动升级到版本 2，保留原有资金、设备和进度。施工、独立副线、机械工人和周期性货运均参与离线模拟。
- 保底收入：无论设备是否运转，每秒固定获得 ¥1，离线时按相同规则和结算上限发放；保底不计工业产值、核心或旧城分红。
- 验证：运行 `node scripts/test-wasteland-foundry.cjs` 检查资源守恒、工程前置与扣费、机器人耗材、周期交付、离线一致性、迁厂与旧存档迁移，无额外依赖。
